Flyweight Pattern

xxx The Flyweight Pattern is a structural design pattern that focuses on reducing memory usage by sharing as much data as possible with similar objects.

✅ Goals:

  • Optimize memory usage.
  • Share common data among multiple objects.

🔧 When to Use:

  • When your application creates a large number of similar objects.
  • When memory usage is a concern.

🛠️ How it Works:

  1. Identify shared data that can be extracted.
  2. Create a Flyweight object to hold this shared data.
  3. Use a factory to manage and reuse Flyweight objects.

📚 Example:

Imagine a text editor where each character is an object. Instead of creating a new object for every character, the Flyweight Pattern allows you to share the same object for characters with the same properties (e.g., font, size).

class Flyweight:
    def __init__(self, shared_state):
        self.shared_state = shared_state

    def operation(self, unique_state):
        print(f"Shared: {self.shared_state}, Unique: {unique_state}")

class FlyweightFactory:
    def __init__(self):
        self._flyweights = {}

    def get_flyweight(self, shared_state):
        if shared_state not in self._flyweights:
            self._flyweights[shared_state] = Flyweight(shared_state)
        return self._flyweights[shared_state]

# Usage
factory = FlyweightFactory()
flyweight1 = factory.get_flyweight("Arial, 12pt")
flyweight1.operation("Character A")
flyweight2 = factory.get_flyweight("Arial, 12pt")
flyweight2.operation("Character B")

📌 Key Points:

  • Shared state is stored in the Flyweight object.
  • Unique state is passed to the Flyweight object when needed.
